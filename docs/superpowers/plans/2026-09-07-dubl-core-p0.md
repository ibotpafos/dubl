# DUBL Core P0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a deterministic, local C++ command-line core that analyses a lead/double WAV pair and emits a safe, inspectable alignment plan.

**Architecture:** `dubl_core` owns audio loading, frame features, constrained correspondence and warp planning. `dubl_analyse` is a thin CLI that writes a versioned JSON report. No ARA, plug-in UI, ML runtime, audio rendering, network access or host integration is included in P0; the public interfaces reserve confidence and model metadata for on-device ML in later increments.

**Tech Stack:** C++20, CMake 3.25+, CTest, no runtime third-party dependency.

**Spec:** `docs/superpowers/specs/2026-09-07-vocal-align-studio-one-design.md`

## Global Constraints

- Target macOS Apple Silicon first; compile with AppleClang and C++20.
- All processing is local, deterministic and offline; never emit audio contents, paths or telemetry in reports.
- P0 accepts mono PCM WAV at 44.1 or 48 kHz only and reports every rejected input explicitly.
- A lower-confidence or unsafe region must yield an unchanged identity mapping, never an invented correction.
- Preserve exact input duration in every generated alignment plan.
- Use Russian material as the future primary benchmark and English material as a mandatory regression set; P0 ships no vocal dataset.
- GPL-3.0 applies to all new source files.

## Interfaces

```cpp
// include/dubl/audio_buffer.hpp
namespace dubl {
struct AudioBuffer { int sample_rate; std::vector<float> samples; };
bool isSupportedSampleRate(int sample_rate) noexcept;
}

// include/dubl/wav_reader.hpp
namespace dubl {
enum class WavError { none, file_open, malformed_riff, unsupported_format,
                      unsupported_channels, unsupported_sample_rate, truncated };
struct WavLoadResult { std::optional<AudioBuffer> audio; WavError error; };
WavLoadResult loadMonoWav(const std::filesystem::path& path);
}

// include/dubl/features.hpp
namespace dubl {
struct FrameFeature { double time_seconds; float rms; float onset; float f0_hz; bool voiced; };
std::vector<FrameFeature> extractFeatures(const AudioBuffer& audio, int hop_samples = 480);
}

// include/dubl/alignment.hpp
namespace dubl {
struct AlignmentPoint { int double_frame; int lead_frame; float confidence; };
struct AlignmentResult { std::vector<AlignmentPoint> points; float overall_confidence; };
AlignmentResult alignFeatures(std::span<const FrameFeature> lead,
                              std::span<const FrameFeature> dub, int max_frame_offset = 200);
}

// include/dubl/warp_plan.hpp
namespace dubl {
struct WarpPoint { double source_seconds; double target_seconds; float pitch_ratio; bool identity; };
struct WarpPlan { std::vector<WarpPoint> points; float confidence; };
WarpPlan makeSafeWarpPlan(const AlignmentResult& alignment,
                          std::span<const FrameFeature> lead,
                          std::span<const FrameFeature> dub,
                          float minimum_confidence = 0.70F);
}
```

- [ ] **Step 3: Implement planner**

Otherwise use aligned target time, clamp consecutive local stretch ratios to `[0.85, 1.18]`, clamp pitch ratio to ±100 cents, force unvoiced pitch ratio to `1.0F`, and mark a point identity if its local alignment confidence is below threshold. Insert source start/end identity anchors so duration is preserved.
